# Simple Live Clock

A simple live clock built using **Vite and React.js**.

Displays the current date and time and updates automatically every second.

## Features

- Displays current date and time
- Updates every second
- Uses `useState` and `useEffect`
- Uses `setInterval()` and `clearInterval()`

## Technologies

- React.js
- Vite
- JavaScript
- Bootstrap
- CSS

## Run Locally

```bash
npm install
npm run dev
```
